<h2>About Netscapeit</h2>

<p>
Netscapeit is a retro-inspired web browser project built around the
classic internet experience of the late 1990s.
</p>

<p>
The goal is to recreate the experience of browsing the web in the
Netscape Navigator era, with support for a companion server called
<b>Xserver</b>.
</p>

<h2>Features</h2>

<ul>
  <li>Retro-inspired browser interface</li>
  <li>Xserver web server integration</li>
  <li>Virtual websites and domains</li>
  <li>Guestbooks and user-published pages</li>
  <li>Classic internet-style homepage</li>
  <li>Firebase integration for cloud features</li>
</ul>

<h2>⚙️ Technology</h2>

<ul>
  <li>TypeScript</li>
  <li>HTML and CSS</li>
  <li>Firebase</li>
  <li>Legacy browser engine integration (planned)</li>
</ul>

<h2>Development</h2>

<p>
Netscapeit is currently in early development. Features and architecture
are still being worked on.
</p>

<h2>Project Goals</h2>

<ul>
  <li>Recreate the classic Netscape browsing experience.</li>
  <li>Build a functional retro web ecosystem.</li>
  <li>Connect Netscapeit to Xserver.</li>
  <li>Support locally hosted websites.</li>
</ul>
