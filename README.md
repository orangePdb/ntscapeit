<h1>Netscapeit</h1>

<p>A browser that feels like the web in 1999. Early development.</p>

<p>This repo is private for now.</p>

<p>
Netscapeit is my take on Netscape Navigator, built to work with Xserver,
a small server that hosts fake sites and domains you can actually visit.
</p>

<h2>What it does</h2>
<ul>
  <li>Old school browser UI</li>
  <li>Works with Xserver</li>
  <li>Virtual sites and domains</li>
  <li>Guestbooks and pages anyone can publish</li>
  <li>Firebase for the online stuff</li>
</ul>

<h2>Built with</h2>
<p>TypeScript, HTML, CSS, Firebase</p>

<h2>Goals</h2>
<ul>
  <li>Recreate the Netscape feel</li>
  <li>Make a tiny working retro web</li>
  <li>Support locally hosted sites</li>
</ul>

<p>Still early, so things will break.</p>
