Netscapeit & Xserver Technical Documentation

This manual provides complete documentation for developers, contributors, and retro-computing enthusiasts seeking to run, extend, or build upon the Netscapeit platform.

1. GETTING STARTED

Netscapeit is composed of two primary tiers:

  1. The Client Browser: A single-page application built in React 19, TypeScript, and Tailwind CSS v4 that faithfully emulates the layout, navigation, menus, and styling of Netscape Communicator 4.7.
  2. The Xserver Backend: An Express.js and TypeScript service (server.ts and xserver/sites.ts) that acts as an RFC 1945 HTTP/1.0 server, dispatching requests across virtual hosts and handling CGI forms.
2. INSTALLATION GUIDE

Prerequisites

  • Node.js version 18.0.0 or higher.
  • npm version 9.0.0 or higher.
  • Git.

Commands

# Step 1: Clone the repository
git clone https://github.com/orangePdb/ntscapeit.git
cd ntscapeit

# Step 2: Install required packages
npm install

# Step 3: Run development server
npm run dev

Available NPM Scripts (package.json)

Script Command Description
npm run dev tsx server.ts Starts the Express server with live Vite HMR middleware.
npm run build vite build Compiles the frontend assets into the dist/ folder.
npm run lint tsc --noEmit Performs TypeScript type-checking across the repository.
npm start node server.ts Runs the production server.
3. XSERVER 1.99 ARCHITECTURE & VIRTUAL HOSTS

Xserver implements a virtual hosting engine configured in xserver/sites.ts. All requests arriving through the browser's Location bar are parsed and routed to their respective virtual website template:

Virtual Host Render Function Description
home.netscapeit.com renderNetcenterPage() Default homepage portal, stock tickers, and featured news.
altavista.xserver.net renderAltaVistaPage() Full-text search engine querying internal indexed docs.
geocities.xserver.net renderGeoCitiesPage() Area51 Cyberia '99 personal homepage & guestbook.
slashdot.xserver.org renderSlashdotPage() News for nerds with threaded comment system.
winamp.xserver.com renderWinampVaultPage() Winamp 2.22 skin vault, shareware & chiptune tracks.
spacejam.xserver.org renderSpaceJamHubPage() Planet 1999 WebRing hub & retro graphics.
xserver.local renderUserPage() Hosts user-published pages created with Composer.
4. CGI-BIN SPECIFICATION

Forms submitted by virtual websites are dispatched to Express REST routes emulating classic CGI-BIN scripts:

POST /api/xserver/cgi/guestbook

Appends an entry to the Cyberia guestbook. Requires fields: name, email, homepage, and message.

POST /api/xserver/cgi/comment

Adds a comment to a Slashdot story. Requires fields: storyId, author, title, and body.

POST /api/xserver/pages

Publishes a custom user website from Composer into Xserver's in-memory storage, assigning a unique slug accessible under http://xserver.local/pages/:slug.

5. NETSCAPE COMPOSER (HTML BUILDER)

Netscape Composer (located in src/components/ComposerView.tsx) enables users to write raw HTML 4.01 markup with live WYSIWYG previewing.

  • Pre-populated retro templates (Personal Homepage, Software Portal, Fan Club).
  • Instant live preview iframe.
  • One-click publication to Xserver with instant visitor counter integration.
6. TROUBLESHOOTING & COMMON ISSUES

Port 3000 Already in Use

If another service is occupying port 3000, specify a custom port:

PORT=3005 npm run dev

Web Audio Autoplay Policy

Modern browsers block audio autoplay until user interaction. Click anywhere inside the Netscapeit window to permit audio before toggling dial-up sound effects.

Iframe Navigation Restrictions

External websites that send an X-Frame-Options: DENY header or restrictive Content-Security-Policy cannot be embedded directly in an iframe. Netscapeit's proxy route strips frame-busting headers for testing environments.

7. EXTENDED FREQUENTLY ASKED QUESTIONS
How do I deploy this to netscapeit.org? [+]
The official portal files in website/ are static HTML, CSS, and vanilla JS. You can deploy them directly to any static host (Cloudflare Pages, Vercel, Netlify, or GitHub Pages) by setting the publish directory to website.
How do I deploy the browser web app to netscp.netscapeit.org? [+]
The browser web app is deployed as a container or Node service running server.ts. In Google Cloud Run or Docker, build using the included Dockerfile/package.json and bind your custom subdomain netscp.netscapeit.org to the service.
Can I contribute new retro virtual sites to Xserver? [+]
Yes! Open xserver/sites.ts, add your site generator function, register its domain in the router table, and submit a pull request to https://github.com/orangePdb/ntscapeit.
