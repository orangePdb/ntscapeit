SOURCE CODE REPOSITORY BUILD (VERIFIED WORKING)

You can build and run Netscapeit locally on any platform that supports Node.js. This launches both the retro browser UI and the companion Xserver 1.99 virtual host router.

Step-by-Step Shell Commands: 
# 1. Clone the repository from GitHub
git clone https://github.com/orangePdb/ntscapeit.git

# 2. Enter project directory
cd ntscapeit

# 3. Install dependencies
npm install

# 4. Start combined server (Vite UI + Express Xserver)
npm run dev

# 5. Open browser at http://localhost:3000

PROJECT CHANGELOG & MILESTONES

Version 0.1.0-alpha (Current Development Milestone)

  • Core Interface: Recreated classic Netscape Communicator 4.7 window chrome, address bar, Personal Bookmarks bar, and animated star shower throbber.
  • Xserver Engine: Implemented RFC 1945 HTTP/1.0 virtual hosting router with raw response header inspector.
  • Simulated 1999 Web: Included Netscape Netcenter, AltaVista Search, GeoCities Cyberia '99 with CGI guestbook, Slashdot '99 with threaded comments, and Winamp Vault.
  • Authoring: Built Netscape Composer for in-browser retro HTML creation and local publishing.
  • Connection Throttling: Added 56k V.90 modem, ISDN, and T1 speed emulation with Web Audio modem handshake synthesis.

Roadmap to Version 1.0

  • Standalone native desktop packaging with Electron / Tauri for Windows, macOS, and Linux.
  • Expanded virtual web directory with over 25 classic late-90s sites.
  • Local offline cache support for browsing without an active internet connection.
  • Exploration of legacy browser engine integration (early Gecko / layout engine mirrors).
